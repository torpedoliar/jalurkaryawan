# Plan 2 — Web App (apps/web) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** React + Vite SPA in `apps/web` covering every role screen of spec §6.1–6.3, first-run setup, settings/backup, running fully against the Plan 1 mock API in the browser via MSW.

**Architecture:** One thin `api.ts` client (fetch + Zod parse with `@bms/shared` schemas, in-memory access token, cookie refresh). `AuthProvider` context holds `Me`; role-guarded routes under one `Layout`. Pages are plain components with local `useState`/`useEffect` — no global store, no data library. `VITE_USE_MOCK=true` starts `msw/browser` worker with `@bms/mock-api` handlers before render. Component tests run in Vitest + jsdom against `msw/node` with the same handlers; one Playwright smoke test runs against `vite` dev server in mock mode.

**Tech Stack:** React 18.3.1, react-router-dom 6.28.0, Vite 5.4.21, @vitejs/plugin-react 4.3.4, zod 3.23.8, msw 2.6.8, xlsx 0.20.3 (SheetJS CDN tarball), Vitest 2.1.8 + jsdom 25.0.1 + @testing-library/react 16.1.0 + @testing-library/dom 10.4.0 + @testing-library/user-event 14.5.2, @playwright/test 1.57.0.

**Spec:** `docs/superpowers/specs/2026-10-13-bus-booking-subproject-a-design.md` (§6.1 admin, §6.2 employee, §6.3 vendor, §7.3 thin Zod client, §5.9 import, §5.12 settings, §8 testing).

**Follow-up plans:** Plan 3 real API (Postgres + Fastify, same contract), Plan 4 deploy (Nginx, backup jobs), Plan 5 mobile.

## Global Constraints

- UI copy in Bahasa Indonesia. Error text shown to users = server `message` verbatim (already Indonesian via `ERROR_MESSAGES`).
- All request/response shapes come from `@bms/shared`; never redeclare a schema in the web app. Endpoints only via `ENDPOINTS`.
- Web error class name: `ApiFailure` (shared already exports zod schema `ApiError`).
- Access token lives in memory only (module variable). Never `localStorage`/`sessionStorage` for tokens.
- Refresh token = httpOnly cookie `bms_refresh` (`Path=/api/auth`). Web POSTs refresh/logout with **no body** and ignores `refreshToken` in responses.
- `fetch` uses `credentials: "same-origin"`; base URL is relative `/api/...` (same origin; no CORS).
- Secret settings (`fcm_service_account`, `backup_share_password`) are never pre-filled: UI shows "Tersimpan"/"Belum diisi" from `{isSet}`; field sent only when the user typed something; explicit "Hapus" sends `""`.
- Settings form validates with shared `SettingsUpdate` before PUT (spec §5.12: same schema client and server).
- Dates: operational date strings `YYYY-MM-DD` via shared `jakartaDate`/`addDays`; display times via `departureAt.slice(11,16)`.
- No new runtime deps beyond Tech Stack. No CSS framework: one `src/styles.css`.
- Pinned exact versions (no `^`), matching Plan 1 style.
- `.env` never committed; `apps/web/.env.example` documents `VITE_USE_MOCK=true`.
- Work on branch `feat/plan-2-web` off master. Never merge/push without user choice.

## Review Focus

1. **Access token expiry mid-session** — a 401 on any call must refresh once via cookie and retry transparently; second 401 logs out to `/login`, never loops. (Task 2 test)
2. **`mustChangePassword` user** — after login every URL shows only the change-password form until changed; server would answer FORBIDDEN otherwise. (Task 3 test)
3. **Server 503 MAINTENANCE during restore** — any call returning MAINTENANCE swaps the whole app to the maintenance screen, which polls `systemStatus` and returns when clear. (Task 2 + Task 3 test)
4. **Suspended employee** — banner shows reason/until and booking wizard submit is disabled; server USER_SUSPENDED still surfaces verbatim if UI misses it. (Task 4 test)
5. **Excel import with bad rows** — preview lists row errors and commit button stays disabled while `errors.length > 0`; temp passwords shown once after commit. (Task 6 test)

```ts
import { ApiError, ENDPOINTS, LoginResponse, Me, type ErrorCode, type SetupRequest } from "@bms/shared";
import type { ZodTypeAny, z } from "zod";

export class ApiFailure extends Error {
  constructor(public code: ErrorCode, message: string, public status: number) {
    super(message);
  }
}

/** Access token lives in memory only; the refresh token is the httpOnly bms_refresh cookie (spec 5.8). */
let token: string | null = null;
export const setToken = (t: string | null) => { token = t; };

export const apiEvents = { maintenance: () => {}, loggedOut: () => {} };

type Query = Record<string, string | undefined>;
interface Opts { body?: unknown; form?: FormData; query?: Query }

/** Auth endpoints never trigger the refresh-and-retry path. */
const NO_RETRY: string[] = [ENDPOINTS.login, ENDPOINTS.refresh, ENDPOINTS.setup, ENDPOINTS.logout];

function send(method: string, path: string, opts: Opts = {}): Promise<Response> {
  const url = new URL(path, location.origin);
  for (const [k, v] of Object.entries(opts.query ?? {})) if (v) url.searchParams.set(k, v);
  const headers: Record<string, string> = {};
  if (token) headers.authorization = `Bearer ${token}`;
  let body: BodyInit | undefined = opts.form;
  if (opts.body !== undefined) {
    headers["content-type"] = "application/json";
    body = JSON.stringify(opts.body);
  }
  return fetch(url.toString(), { method, headers, body, credentials: "same-origin" });
}

let refreshing: Promise<Me | null> | null = null;

/** POST with no body: the server reads the cookie. Concurrent 401s share one refresh. */
export function restoreSession(): Promise<Me | null> {
  refreshing ??= send("POST", ENDPOINTS.refresh)
    .then(async (r) => {
      if (!r.ok) return null;
      const out = LoginResponse.parse(await r.json());
      token = out.accessToken;
      return out.user;
    })
    .catch(() => null)
    .finally(() => { refreshing = null; });
  return refreshing;
}

async function toFailure(res: Response): Promise<ApiFailure> {
  const parsed = ApiError.safeParse(await res.json().catch(() => null));
  return parsed.success
    ? new ApiFailure(parsed.data.code, parsed.data.message, res.status)
    : new ApiFailure("VALIDATION_ERROR", `Permintaan gagal (HTTP ${res.status}).`, res.status);
}

async function call(method: string, path: string, opts: Opts = {}): Promise<Response> {
  let res = await send(method, path, opts);
  const retryable = !NO_RETRY.includes(path);
  if (res.status === 401 && retryable && token && (await restoreSession())) res = await send(method, path, opts);
  if (res.ok) return res;
  const f = await toFailure(res);
  if (f.code === "MAINTENANCE") apiEvents.maintenance();
  if (f.status === 401 && retryable) {
    token = null;
    apiEvents.loggedOut();
  }
  throw f;
}

async function request<T extends ZodTypeAny>(method: string, path: string, schema: T, opts?: Opts): Promise<z.output<T>> {
  const res = await call(method, path, opts);
  return schema.parse(res.status === 204 ? undefined : await res.json());
}

export const api = {
  get: <T extends ZodTypeAny>(path: string, schema: T, query?: Query) => request("GET", path, schema, { query }),
  post: <T extends ZodTypeAny>(path: string, schema: T, body?: unknown) => request("POST", path, schema, { body }),
  put: <T extends ZodTypeAny>(path: string, schema: T, body: unknown) => request("PUT", path, schema, { body }),
  upload: <T extends ZodTypeAny>(path: string, schema: T, form: FormData) => request("POST", path, schema, { form }),
  /** Needs the bearer header, so a plain <a href> cannot do it. */
  async download(path: string, fileName: string): Promise<void> {
    const blob = await (await call("GET", path)).blob();
    const a = document.createElement("a");
    a.href = URL.createObjectURL(blob);
    a.download = fileName;
    a.click();
    URL.revokeObjectURL(a.href);
  },
};

export async function login(nik: string, password: string): Promise<Me> {
  const out = await api.post(ENDPOINTS.login, LoginResponse, { nik, password });
  token = out.accessToken; // refreshToken in the body is ignored on web; the cookie carries it
  return out.user;
}

import { ApiFailure } from "./api";

export function errorText(e: unknown): string {
  if (e instanceof ApiFailure) return e.message;
  if (e instanceof ZodError) return e.issues[0]?.message ?? "Data tidak valid.";
  return "Terjadi kesalahan. Coba lagi.";
}

/** Load on mount and whenever deps change; stale responses are dropped. */
export function useLoad<T>(fn: () => Promise<T>, deps: unknown[]) {
  const [data, setData] = useState<T>();
  const [error, setError] = useState<string | null>(null);
  const [tick, setTick] = useState(0);
  useEffect(() => {
    let live = true;
    setError(null);
    fn().then((d) => { if (live) setData(d); }, (e: unknown) => { if (live) setError(errorText(e)); });
    return () => { live = false; };
  }, [...deps, tick]); // eslint-disable-line react-hooks/exhaustive-deps
  return { data, error, reload: useCallback(() => setTick((n) => n + 1), []) };
}

/** Wrap a mutation: tracks busy, shows the server message, resolves undefined on failure. */
export function useAction() {
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState<string | null>(null);
  async function run<T>(fn: () => Promise<T>): Promise<T | undefined> {
    setBusy(true);
    setError(null);
    try {
      return await fn();
    } catch (e) {
      setError(errorText(e));
      return undefined;
    } finally {
      setBusy(false);
    }
  }
  return { busy, error, setError, run };
}

export function ErrorText({ error }: { error: string | null | undefined }) {
  return error ? <p role="alert" className="error">{error}</p> : null;

  const [me, setMe] = useState<Me | null>(null);
  const [maintenance, setMaintenance] = useState(false);
  const [bootKey, setBootKey] = useState(0);

  useEffect(() => {
    apiEvents.maintenance = () => setMaintenance(true);
    apiEvents.loggedOut = () => setMe(null);
  }, []);

  useEffect(() => {
    let live = true;
    (async () => {
      const { needsSetup } = await api.get(ENDPOINTS.setupStatus, SetupStatus);
      if (needsSetup) return live && setBoot("setup");
      const m = await loadSession();
      if (live) { setMe(m); setBoot("ready"); }
    })().catch(() => { if (live) setBoot("ready"); }); // MAINTENANCE already flipped the flag; anything else lands on Login
    return () => { live = false; };
  }, [bootKey]);

  // Restore ends every session (spec 5.11): re-run boot, which lands on Login.
  const back = useCallback(() => { setMaintenance(false); setBootKey((k) => k + 1); }, []);
  const signOut = useCallback(async () => { await logout(); setMe(null); }, []);

  if (maintenance) return <Maintenance onDone={back} />;
  if (boot === "loading") return <div className="center">Memuat…</div>;
  if (boot === "setup") return <AuthContext.Provider value={{ me, setMe, signOut }}><Setup onDone={(m) => { setMe(m); setBoot("ready"); }} /></AuthContext.Provider>;

  const pages = me ? PAGES.filter((p) => p.roles.includes(me.role)) : [];
  return (
    <AuthContext.Provider value={{ me, setMe, signOut }}>
      {!me ? <Login />
        : me.mustChangePassword ? <ChangePassword forced />
        : (
          <Routes>
            <Route element={<Layout pages={pages} />}>
              {pages.map((p) => <Route key={p.path} path={p.path} element={p.element} />)}
              <Route path="*" element={<Navigate to={pages[0]!.path} replace />} />
            </Route>
          </Routes>
        )}
    </AuthContext.Provider>
  );
}

const IMPORT_HEADERS: Record<string, string> = { NIK: "nik", Nama: "name", Departemen: "department", "No HP": "phone" };

/** First sheet as raw rows with API field names. Validation is the server's job (preview). */
export async function readXlsx(file: File): Promise<unknown[]> {
  const wb = read(await file.arrayBuffer());
  const rows = utils.sheet_to_json<Record<string, unknown>>(wb.Sheets[wb.SheetNames[0]!]!, { defval: "" });
  return rows.map((r) => Object.fromEntries(Object.entries(r).map(([k, v]) => [IMPORT_HEADERS[k.trim()] ?? k, v])));
}

/** Prev/next for `Paginated` lists (mock and backend page size 50). */
export function Pager({ data, page, onPage }: { data?: { total: number; pageSize: number }; page: number; onPage(p: number): void }) {
  const pages = data ? Math.max(1, Math.ceil(data.total / data.pageSize)) : 1;
  return (
    <div className="row">
      <button disabled={page <= 1} onClick={() => onPage(page - 1)}>Sebelumnya</button>
      <span>Halaman {page} dari {pages}</span>
      <button disabled={page >= pages} onClick={() => onPage(page + 1)}>Berikutnya</button>
    </div>
  );
}

/** Save a blob through a temporary <a download>. */
export function saveBlob(blob: Blob, fileName: string): void {
  const a = document.createElement("a");
  a.href = URL.createObjectURL(blob);
  a.download = fileName;
  a.click();
  URL.revokeObjectURL(a.href);
}

import { BOOKING_STATUS_TEXT, DIRECTION_LABEL, ErrorText, downloadXlsx, pct, today, useLoad } from "../../ui";

export function Reports() {
  const [from, setFrom] = useState(defaultRange().from);
  const [to, setTo] = useState(defaultRange().to);
  const occ = useLoad(() => api.get(ENDPOINTS.occupancy, z.array(OccupancyRow), { from, to }), [from, to]);

  const lookups = useLoad(() => Promise.all([
    api.get(ENDPOINTS.routes, z.array(Route)), api.get(ENDPOINTS.shifts, z.array(Shift)),
  ]), []);
  const [routes = [], shifts = []] = lookups.data ?? [];
  const code = (id: string) => routes.find((r) => r.id === id)?.code ?? id;
  const shiftName = (id: string) => shifts.find((s) => s.id === id)?.name ?? id;

    (occ.data ?? []).map((r) => ({ Tanggal: r.date, Rute: r.routeCode, "Nama rute": r.routeName, Shift: r.shiftName, Arah: DIRECTION_LABEL[r.direction], Trip: r.trips, Kuota: r.capacity, Terisi: r.booked, "%": pct(r.booked, r.capacity), Ditolak: r.rejected })),
    `keterisian-${from}-${to}.xlsx`,
  );

import { useState } from "react";
import { z } from "zod";
import { addDays, ENDPOINTS, OccupancyRow, RejectedRequest, Shift } from "@bms/shared";
import { api } from "../../api";
import { ErrorText, downloadXlsx, pct, today, useLoad } from "../../ui";

/** Spec 6.3: satu dashboard vendor — keterisian, rute yang sering penuh, permintaan ditolak, semua bisa diekspor. Tanpa data karyawan (peran vendor tidak boleh membaca /api/users). */
export function VendorHome() {
  const [from, setFrom] = useState(addDays(today(), -6));
  const [to, setTo] = useState(today());
  const occ = useLoad(() => api.get(ENDPOINTS.occupancy, z.array(OccupancyRow), { from, to }), [from, to]);
  const rejected = useLoad(() => api.get(ENDPOINTS.rejected, z.array(RejectedRequest), { from, to }), [from, to]);
  const lookups = useLoad(() => api.get(ENDPOINTS.shifts, z.array(Shift)), []);
  const [shifts = []] = lookups.data ?? [];
  const shiftName = (id: string) => shifts.find((s) => s.id === id)?.name ?? id;

  const often = new Map<string, { label: string; full: number; days: number }>();
  for (const r of occ.data ?? []) {
    const label = `${r.routeCode} ${r.routeName} ${r.shiftName} ${DIRECTION_LABEL[r.direction]}`;
    const e = often.get(label) ?? { label, full: 0, days: 0 };
    e.days++;
    if (r.booked >= r.capacity) e.full++;
    often.set(label, e);
  }

  return (
    <>
      <h1>Dashboard Vendor</h1>
      <ErrorText error={occ.error ?? rejected.error ?? lookups.error} />
      <div className="card row">
        <label>Dari tanggal<input type="date" value={from} onChange={(e) => setFrom(e.target.value)} /></label>
        <label>Sampai tanggal<input type="date" value={to} onChange={(e) => setTo(e.target.value)} /></label>
      </div>

      <section className="card">
        <table>
          <caption>Keterisian</caption>
          <thead><tr><th>Tanggal</th><th>Rute</th><th>Shift</th><th>Arah</th><th>Terisi</th><th>Ditolak</th></tr></thead>
          <tbody>

  backup_run_time: { label: "Jam backup", kind: "time" },
  backup_retention_days: { label: "Simpan backup (hari)", kind: "int" },
  backup_share_enabled: { label: "Salin ke network share", kind: "bool" },
  backup_share_path: { label: "Path share", kind: "text", placeholder: "//host/share/folder" },
  backup_share_username: { label: "Username share", kind: "text" },
  backup_share_password: { label: "Password share", kind: "secret" },
} as const satisfies Record<keyof Settings, { label: string; kind: string; placeholder?: string }>;

type Key = keyof typeof KEYS;
type Draft = Record<string, string | boolean>;
/** The two keys whose values the API never returns. `SECRET_SETTING_KEYS` from @bms/shared is the same list. */
type SecretKey = "fcm_service_account" | "backup_share_password";
/** Secrets never come back from the API, so the draft tracks only what the user typed. `key in pending` marks a send; `""` clears. */
type Pending = Partial<Record<SecretKey, string>>;

const TAB_KEYS = ["booking", "notification", "security", "backup"] as const;
type Tab = (typeof TAB_KEYS)[number];
const TAB_LABEL: Record<Tab, string> = { booking: "Booking", notification: "Notifikasi", security: "Keamanan", backup: "Backup" };
const TestResult = z.object({ ok: z.boolean(), message: z.string() });
const mb = (n: number) => `${(n / 1048576).toFixed(1)} MB`;

/** Secrets are not in the draft: the API never returns their values, only `{isSet}`. */
function toDraft(v: SettingsView): Draft {
  const out: Draft = {};
  for (const [k, m] of Object.entries(KEYS)) {
    if (m.kind === "file" || m.kind === "secret") continue;
    out[k] = m.kind === "bool" ? Boolean(v[k as keyof SettingsView]) : String(v[k as keyof SettingsView]);
  }
  return out;
}

export function SettingsScreen() {
  const { signOut } = useAuth();
  const [tab, setTab] = useState<Tab>("booking");
  const [draft, setDraft] = useState<Draft | null>(null);
  const [pending, setPending] = useState<Pending>({});
  const [msg, setMsg] = useState("");
  const [file, setFile] = useState("");
  const [pw, setPw] = useState("");
  const [confirm, setConfirm] = useState("");
  const save = useAction();
  const act = useAction();
  const load = useLoad(() => api.get(ENDPOINTS.settings, SettingsView), []);
  const list = useLoad(() => api.get(ENDPOINTS.backups, z.array(BackupFile)), []);

  const value = load.data ? draft ?? toDraft(load.data) : {};
  const set = (k: Key) => (v: string | boolean) => setDraft({ ...value, [k]: v });

  async function submit(e: FormEvent) {
    e.preventDefault();
    setMsg("");
    const body: Record<string, unknown> = {};
    for (const [k, m] of Object.entries(KEYS)) {
      if (m.kind === "file" || m.kind === "secret") { if (k in pending) body[k] = pending[k as SecretKey]; continue; }
      const v = value[k];
      if (m.kind === "int" && (v === "" || v === undefined)) continue;
      body[k] = m.kind === "int" ? Number(v) : v;
    }
    // Same schema as the server: one copy of the ranges, and errorText renders the issue in Indonesian.
    const parsed = SettingsUpdate.safeParse(body);
    if (!parsed.success) { save.setError(errorText(parsed.error)); return; }
    if (!await save.run(() => api.put(ENDPOINTS.settings, SettingsView, parsed.data))) return;
    setDraft(null);
    setPending({});
    setMsg("Pengaturan disimpan.");
    load.reload();
    list.reload();
  }

  async function pickFcm(f: File | undefined) {
    if (f) setPending((p) => ({ ...p, fcm_service_account: await f.text() }));
  }

  function Row({ k }: { k: Key }) {
    const m = KEYS[k];
    const id = `s-${k}`;
    return (
      <label htmlFor={id}>
        {m.label}
        {m.kind === "int" && <input id={id} type="number" value={String(value[k])} onChange={(e) => set(k)(e.target.value)} />}
        {m.kind === "time" && <input id={id} type="time" value={String(value[k])} onChange={(e) => set(k)(e.target.value)} />}
        {m.kind === "text" && <input id={id} value={String(value[k])} placeholder={m.placeholder} onChange={(e) => set(k)(e.target.value)} />}
        {m.kind === "bool" && <input id={id} type="checkbox" checked={Boolean(value[k])} onChange={(e) => set(k)(e.target.checked)} />}
        {m.kind === "file" && <input id={id} type="file" accept=".json" onChange={(e) => void pickFcm(e.target.files?.[0])} />}
        {m.kind === "secret" && <input id={id} type="password" value={pending[k as SecretKey] ?? ""} onChange={(e) => setPending((s) => ({ ...s, [k as SecretKey]: e.target.value }))} />}
      </label>
    );
  }

  // backup_share_password has no value to show, so its row is the status paragraph + Hapus button instead.
  const rows = SETTING_GROUPS[tab].filter((k) => k !== "backup_share_password") as Key[];

  async function upload(f: File | undefined) {
    if (!f) return;
    const form = new FormData();
    form.append("file", f);
    if (await act.run(() => api.upload(ENDPOINTS.backupUpload, BackupFile, form))) { setMsg("File backup ditambahkan."); list.reload(); }
  }

  return (
    <>
      <h1>Pengaturan</h1>
      <ErrorText error={load.error ?? save.error} />
      {msg && <p role="status">{msg}</p>}
      <form onSubmit={submit}>
        <nav>{TAB_KEYS.map((k) => <button key={k} type="button" onClick={() => setTab(k)}>{TAB_LABEL[k]}</button>)}</nav>

        <section className="card">
          {rows.map((k) => <Row key={k} k={k} />)}
          {tab === "backup" && (
            <>
              <p>Password share: {load.data?.backup_share_password.isSet ? "Tersimpan" : "Belum diisi"}</p>
              <div className="row">
                <button type="button" onClick={() => setPending((s) => ({ ...s, backup_share_password: "" }))}>Hapus</button>
                <button type="button" disabled={act.busy} onClick={async () => setMsg((await act.run(() => api.post(ENDPOINTS.settingsTestShare, TestResult)))?.message)}>Tes koneksi share</button>
              </div>
            </>
          )}
          {tab === "notification" && (
            <div className="row">
              <button type="button" disabled={act.busy} onClick={async () => setMsg((await act.run(() => api.post(ENDPOINTS.settingsTestPush, TestResult)))?.message)}>Tes kirim push</button>
            </div>
          )}
        </section>

        <button className="primary" disabled={save.busy}>Simpan pengaturan</button>
      </form>

      {tab === "backup" && (
        <section className="card">
          <h2>Backup database</h2>
          <ErrorText error={list.error ?? act.error} />
          <div className="row">
            <button type="button" disabled={act.busy} onClick={async () => { if (await act.run(() => api.post(ENDPOINTS.backupRun, BackupFile))) { setMsg("Backup dibuat."); list.reload(); } }}>Backup sekarang</button>
            <label htmlFor="up">File backup<input id="up" type="file" accept=".dump" onChange={(e) => void upload(e.target.files?.[0])} /></label>
          </div>
          {list.data?.length === 0 && <p>Belum ada file backup.</p>}
          {(list.data?.length ?? 0) > 0 && (
            <table>
              <caption>Daftar backup</caption>
              <thead><tr><th>Nama file</th><th>Ukuran</th><th>Dibuat</th><th>Network share</th><th /></tr></thead>
              <tbody>
                {list.data?.map((b) => (
                  <tr key={b.name}>
                    <td>{b.name}</td><td>{mb(b.sizeBytes)}</td><td>{b.createdAt}</td>
                    <td>{b.copiedToShare ? "Tersalin" : "Belum"}</td>
                    <td><button type="button" onClick={() => void api.download(ENDPOINTS.backupDownload(b.name), b.name)}>Unduh</button></td>
                  </tr>
                ))}
              </tbody>
            </table>
          )}
        </section>
      )}

      {tab === "backup" && (
        <section className="card">
          <h2>Pulihkan dari backup</h2>
          <p>Seluruh sesi login akan diakhiri setelah pemulihan selesai, dan kamu diminta masuk lagi.</p>
          <ErrorText error={act.error} />
          <label htmlFor="rf">File backup tujuan<input id="rf" value={file} onChange={(e) => setFile(e.target.value)} placeholder="bms-20261014-000000.dump" /></label>
          <label htmlFor="rp">Password kamu<input id="rp" type="password" value={pw} onChange={(e) => setPw(e.target.value)} /></label>
          <label htmlFor="rc">Ketik RESTORE<input id="rc" value={confirm} onChange={(e) => setConfirm(e.target.value)} /></label>
          <button
            className="primary"
            disabled={act.busy || !file || confirm !== "RESTORE"}
            onClick={async () => {
              // confirm is the literal the schema requires; the button stays disabled until the field matches.
              const out = await act.run(() => api.post(ENDPOINTS.restore, RestoreRequest, { fileName: file, password: pw, confirm: "RESTORE" }));
              if (out) { setMsg(`Backup pra-pemulihan: ${out.preRestore.name}`); await signOut(); }
            }}
          >
            Pulihkan database
          </button>
        </section>
      )}
    </>
  );
}
```

Tiga keputusan yang bukan gaya:

- **Label lewat `htmlFor` + `id`,** bukan label yang membungkus input seperti halaman lain. `Password share` muncul di layar ini sebagai teks status dan sebagai nama input, dan `File backup` (unggahan) harus berbeda dari `File backup tujuan` (restore) — `getByLabelText` butuh pencocokan persis yang tidak ambigu.
- **Dua `useAction`:** `save` untuk form, `act` untuk tombol aksi, unggahan, dan restore. Satu saja akan mematikan `Simpan pengaturan` saat `Tes koneksi share` berjalan.
- **`SettingsUpdate.safeParse` di klien** sebelum PUT, memakai skema `@bms/shared` yang sama dengan server. Nilai di luar batas tertahan di klien dengan pesan Zod yang sama; server tetap memvalidasi ulang karena ia tidak pernah memercayai klien.

Empat keputusan yang bukan gaya:

- **`selectOption({ label })`, bukan `{ value }`.** Label adalah yang dilihat pengguna (`Siang`, `Jemput`, `R2 Bekasi Timur`, `1. Halte Bulak Kapal`); `value` adalah id internal (`siang`, `PICKUP`, `r2`, `r2s1`) yang bisa berubah tanpa mengubah apa pun bagi pengguna. Tes yang membaca label gagal justru saat label rusak.
- **`Tanggal` tetap memakai `DATE` sebagai `value`**, karena `Book.tsx` merender tanggal mentah (`2026-10-15`) sebagai teks `option`, jadi label dan value di situ sama.

- **Cancel diperiksa lewat hilangnya tombol**, bukan hanya munculnya teks `Dibatalkan`. `Home.tsx` hanya merender tombol saat `status === "BOOKED"`, jadi tombol yang masih ada berarti `list.reload()` belum membawa status baru.
